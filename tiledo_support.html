Support – TileDo

Help, contact and information about the TileDo task manager

Last updated: October 15, 2026

This page provides support information for the TileDo application. If you have a question, found a problem, or want to send feedback, you can contact the developer using the email address below.

1. About the app

TileDo is a simple and convenient task management application designed to help users organise everyday tasks, plans, work and study.

Users can create tasks, set dates and times, use reminders, divide tasks into subtasks and organise everything using categories.

The application includes features such as:

  • creating and editing tasks,
  • setting due dates and times,
  • local task reminders,
  • recurring tasks,
  • subtasks and task progress tracking,
  • custom task categories,
  • important task marking,
  • searching and filtering tasks,
  • weekly calendar view,
  • completed task statistics,
  • task archive,
  • light and dark themes,
  • multiple language support.

4. Common issues

The app does not open or freezes

Close TileDo completely and open it again. If the problem continues, restart your device and make sure you have the latest version of the application installed.

My tasks disappeared

TileDo stores task information locally on your device. Removing the application, clearing application data, resetting the device, or certain system operations may remove locally stored tasks.

Important: TileDo currently stores task data locally. Uninstalling the application may remove your saved tasks.

I do not receive task reminders

TileDo uses local notifications for task reminders. Make sure notifications are enabled for TileDo in your device settings.

Also make sure that the task has:

  • a valid date,
  • a valid time,
  • the reminder option enabled,
  • a reminder time that has not already passed.

I denied notification permission

If notification permission was denied, you can enable it later in your device system settings.

On iPhone, open: Settings → Notifications → TileDo and enable notifications.

A recurring task did not create the next task

Make sure the task is configured as recurring and has a valid date. The next occurrence is created when the current recurring task is marked as completed.

Subtask progress is not updated

Try reopening the task after changing a subtask. The progress indicator is based on the number of completed subtasks compared with the total number of subtasks.

A completed task disappeared from the home screen

Completed tasks are normally removed from the active task list. You can view completed tasks using the completed tasks section or the archive.

The wrong tasks are displayed after using a filter

Try selecting the "All" view again or clear the currently selected category and search text.

TileDo allows tasks to be filtered by date, importance, completion status, category and other criteria.

The language did not change immediately

After changing the language in TileDo settings, save the changes. If some text is not updated immediately, close and reopen the application.

The selected theme is not displayed correctly

TileDo supports light, dark and system themes. If the system theme is selected, the appearance of the application follows your device appearance settings.

5. Notifications

TileDo can send local notifications for task reminders.

These reminders are created directly on your device. TileDo does not require an online account or server connection to schedule standard task reminders.

Note: Notification delivery can depend on device settings, notification permissions and operating system restrictions.

6. Accounts and login

TileDo does not require creating an account or logging in.

You can start creating and organising tasks immediately after opening the application.

7. Data storage

TileDo stores task-related data locally on your device.

This includes information such as:

  • tasks,
  • task descriptions,
  • dates and times,
  • subtasks,
  • task categories,
  • task completion status,
  • recurring task settings.

The main task management features do not require cloud synchronization or an online account.

8. Privacy

TileDo does not require users to create an account or provide an email address in order to use the main task management features.

The application is designed primarily around local storage of task information on the user's device.

You can read the full privacy policy here:

Privacy Policy – TileDo

9. Data deletion

Individual tasks and subtasks can be deleted directly inside TileDo.

Completed tasks can also be managed using the completed tasks and archive sections.

If you want to remove all locally stored TileDo data, you can use the application's data management options, if available, or uninstall the application from your device.

10. Task reminders and recurring tasks

TileDo allows users to create reminders for scheduled tasks. Reminders can be configured for a specific task date and time.

Tasks can also repeat according to the selected recurrence option, including supported daily, weekly, monthly or selected-day schedules.

When a recurring task is completed, TileDo can create the next occurrence automatically.

11. Categories and filters

TileDo allows tasks to be organised using categories. Users can create custom categories and use them to filter the task list.

Additional views allow users to quickly see tasks for today, tomorrow, the current week, overdue tasks, important tasks and completed tasks.

12. Statistics and archive

TileDo provides statistics to help users review their task activity and completed work.

The archive provides access to tasks that are no longer part of the main active task list.
