Privacy Policy – TileDo

Last updated: August 31, 2026

Your privacy is important to us. This Privacy Policy explains what data is processed when using the TileDo application and how user privacy is protected.

TileDo is a task management and productivity application designed to help users organize daily tasks, create categories, manage subtasks, schedule reminders, create recurring tasks, review completed tasks, and monitor productivity statistics.

1. What data do we collect?

TileDo does not collect personal data from users for storage on external servers.

The application does not require creating an account, logging in, or providing information such as:

  • name
  • email address
  • phone number
  • home address
  • precise location
  • contacts
  • photos
  • payment information

The information created by the user inside TileDo is stored locally on the user's device and is used only to provide the application's functionality.

2. Tasks and task-related data

TileDo allows users to create and manage tasks. In order to provide this functionality, the application may locally store information such as:

  • task titles
  • task descriptions or notes
  • task dates
  • task times
  • task completion status
  • task completion date and time
  • task priority
  • subtasks
  • task categories
  • category names
  • category icons
  • category colors
  • reminder settings
  • recurring task settings

This information is stored locally on the user's device. TileDo does not automatically upload task content to an external server.

3. Subtasks

TileDo allows users to divide tasks into smaller subtasks. Subtask titles and completion states are stored locally on the device.

If enabled in the application settings, TileDo may automatically mark a parent task as completed when all of its subtasks have been completed.

Subtask information is not automatically transmitted to external servers.

4. Categories

TileDo includes built-in task categories and allows users to create custom categories.

The application may locally store:

  • category names
  • selected category icons
  • selected category colors
  • information about which category is assigned to a task

Custom category information remains on the user's device.

5. Reminders and notifications

TileDo may use local notifications to remind users about scheduled tasks.

When the user enables a reminder, the application may process information such as:

  • task title
  • scheduled task date
  • scheduled task time
  • selected reminder time

This information is used to schedule a notification directly on the user's device. TileDo does not require a remote notification server to provide its local reminder functionality.

Depending on the operating system version, TileDo may request permission to display notifications.

Users may disable notifications at any time through the device settings.

6. Recurring tasks

TileDo allows users to create recurring tasks, including tasks repeated daily, weekly, monthly, on weekdays, or on selected days.

Recurrence settings are stored locally and are used to generate the next task occurrence when appropriate.

Recurring task information is not automatically uploaded to external servers.

7. Statistics

TileDo may calculate productivity statistics based on locally stored task data.

Statistics may include information such as:

  • number of completed tasks
  • number of tasks completed today
  • number of tasks completed during the current week
  • task completion percentage
  • current productivity streak
  • activity during the last seven days
  • most frequently completed task category
  • most productive day of the week

These statistics are calculated locally using data stored on the user's device. TileDo does not automatically send productivity statistics to us or to external servers.

8. Archive

Completed tasks may appear in the TileDo archive.

The archive may contain information such as:

  • task title
  • task category
  • completion date and time
  • task description
  • completion status

Archive information is stored locally on the device.

Users may restore completed tasks from the archive when this functionality is available in the application.

9. Local storage

TileDo uses local device storage to provide its core functionality and remember user preferences.

Local storage may include:

  • tasks
  • subtasks
  • task descriptions
  • task categories
  • task completion information
  • reminder settings
  • recurrence settings
  • application theme settings
  • default task time settings
  • default reminder settings
  • other application preferences

The application may use a local database and local application preferences to store this information.

If the user deletes TileDo or clears the application's data through the device settings, locally stored tasks, preferences, statistics, categories, and other application data may be permanently deleted.

10. Application settings

TileDo may locally remember preferences selected by the user, including:

  • light, dark, or system theme
  • default task time
  • default reminder settings
  • automatic task completion preferences

These preferences remain on the user's device and are used only to customize the application experience.

11. Ads and analytics

In its current version, TileDo:

  • does not display third-party advertisements,
  • does not use third-party analytics services,
  • does not use third-party tracking services,
  • does not sell user data,
  • does not create advertising profiles based on task content.

If advertising, analytics, or other third-party services are introduced in a future version of TileDo, this Privacy Policy will be updated accordingly.

12. App permissions

TileDo may request or use certain Android system permissions required for application functionality.

Depending on the device and operating system version, these may include:

  • Notification permission – used to display task reminders.
  • Receive boot completed – may be used to support reminder functionality after the device has restarted.
  • Vibration – may be used by task notifications.
  • Internet and network state – may be included for application, platform, or network-related functionality, but TileDo does not use these permissions to upload the user's task database to our servers.

TileDo does not require access to the following features for its core task management functionality:

  • camera
  • microphone
  • precise location
  • contacts
  • SMS messages
  • call history
  • photos or media library
  • health information

13. Internet connection

TileDo's main task management functionality is designed to operate using locally stored data.

Task titles, task descriptions, categories, subtasks, completion history, productivity statistics, and reminder preferences are not automatically uploaded by TileDo to our servers.

When TileDo is downloaded or updated through an application store, the store provider may process technical, diagnostic, purchase-related, device, or account-related information according to its own privacy policy.

TileDo does not control data processing performed independently by the application store or operating system provider.

14. Sharing data with third parties

TileDo does not automatically share the content of the user's tasks, subtasks, categories, archive, or productivity statistics with third parties.

TileDo does not sell personal information or task content.

If a user manually shares information outside the application, for example by taking a screenshot or copying task information to another application, that action is controlled by the user.

15. Data retention and deletion

Task information and application preferences are generally stored on the user's device until they are deleted by the user or until application data is removed.

Users may delete individual tasks directly inside TileDo.

Depending on the available application settings, users may also remove larger collections of locally stored task data.

Uninstalling TileDo or clearing its application data through the operating system settings may delete locally stored information.

16. Security

TileDo stores its core task information locally and does not operate a remote account system for storing the user's task database.

Keeping task information locally reduces the amount of user-created content transmitted over the internet.

Users are responsible for protecting access to their own device, especially when the device is shared with other people.

17. Children's privacy

TileDo does not require users to create an account or provide their age, name, email address, location, or other personal information.

The application does not knowingly collect personal information from children through a remote account or server system.

Parents or guardians are encouraged to supervise general device usage and application installation settings when TileDo is used by younger users.

18. Third-party services

TileDo may rely on operating system functionality and application distribution platforms such as Google Play or the Apple App Store.

These platforms may independently process information according to their own terms and privacy policies.

TileDo is not responsible for independent data processing performed by third-party platforms outside the application.

19. Future features

TileDo may receive new functionality in future versions.

If a future update introduces features that change how user data is collected, processed, transmitted, or shared, this Privacy Policy will be updated accordingly.

20. Changes to this Privacy Policy

We may update this Privacy Policy occasionally to reflect changes to TileDo, operating system requirements, legal requirements, or application functionality.

Any updated version will include a revised date at the top of this page.

Users are encouraged to review this Privacy Policy from time to time.
